## What is ESP-NN?

**ESP-NN** (Espressif Neural Network) is a library that **accelerates neural network operations** on ESP32 chips using optimized assembly code.

**Key Benefits:**
- ✅ **5-10x faster** inference than standard TensorFlow Lite
- ✅ **Native ESP32 optimization** - uses ESP32-S3 instructions
- ✅ **Automatic acceleration** - no code changes needed
- ✅ **Low memory usage** - optimized for embedded devices
- ✅ **Free and open source** - maintained by Espressif

**What it accelerates:**
- Fully connected layers (Dense)
- ReLU activation
- Softmax activation
- Convolution operations
- Pooling operations

## How ESP-NN Works (Behind the Scenes)

### Without ESP-NN (Slow)

```c
// Standard TFLite operations (C code)
for (int i = 0; i < 16; i++) {
    output[i] = 0;
    for (int j = 0; j < 25; j++) {
        output[i] += input[j] * weights[j][i];  // Slow!
    }
    output[i] += bias[i];
    output[i] = max(0, output[i]);  // ReLU
}
```

**Performance**: ~50-100ms per inference

### With ESP-NN (Fast)

```c
// ESP-NN optimized operations (assembly)
esp_nn_fully_connected_s8(
    input, weights, bias, output,
    input_size, output_size
);  // 5-10x faster!
```

**Performance**: ~10-15ms per inference

**How?**
- Uses ESP32-S3 SIMD instructions
- Processes multiple values at once
- Optimized memory access patterns
- Hand-tuned assembly code

### Step 3: Implement ML Inference

**File**: `components/ml_inference/ml_inference.c`


```c
#include "ml_inference.h"
#include "model_data.h"
#include "tensorflow/lite/micro/micro_mutable_op_resolver.h"
#include "tensorflow/lite/micro/micro_interpreter.h"
#include "tensorflow/lite/micro/system_setup.h"
#include "tensorflow/lite/schema/schema_generated.h"
#include "esp_log.h"
#include "esp_timer.h"

static const char *TAG = "ML_INFERENCE";

// TFLite Micro components
static const tflite::Model* model = nullptr;
static tflite::MicroInterpreter* interpreter = nullptr;
static TfLiteTensor* input = nullptr;
static TfLiteTensor* output = nullptr;

// Tensor arena (adjust size if needed)
constexpr int kTensorArenaSize = 10 * 1024;  // 10KB
static uint8_t tensor_arena[kTensorArenaSize];

// Performance tracking
static uint32_t last_inference_time_ms = 0;
static bool initialized = false;

bool ml_inference_init(void) {
    ESP_LOGI(TAG, "Initializing ML inference with ESP-NN acceleration...");
    
    // Load model
    model = tflite::GetModel(model_data);
    if (model->version() != TFLITE_SCHEMA_VERSION) {
        ESP_LOGE(TAG, "Model schema version mismatch!");
        return false;
    }
    ESP_LOGI(TAG, "✅ Model loaded (version %d)", model->version());
    
    // Register operations
    // ESP-NN automatically accelerates these operations!
    static tflite::MicroMutableOpResolver<3> resolver;
    resolver.AddFullyConnected();  // ← ESP-NN accelerated!
    resolver.AddRelu();            // ← ESP-NN accelerated!
    resolver.AddSoftmax();
    
    ESP_LOGI(TAG, "✅ Operations registered (ESP-NN acceleration enabled)");
    
    // Create interpreter
    static tflite::MicroInterpreter static_interpreter(
        model, resolver, tensor_arena, kTensorArenaSize);
    interpreter = &static_interpreter;
    
    // Allocate tensors
    TfLiteStatus allocate_status = interpreter->AllocateTensors();
    if (allocate_status != kTfLiteOk) {
        ESP_LOGE(TAG, "AllocateTensors() failed!");
        return false;
    }
    
    // Get input/output tensors
    input = interpreter->input(0);
    output = interpreter->output(0);
    
    ESP_LOGI(TAG, "✅ Tensors allocated");
    ESP_LOGI(TAG, "   Input:  [%d, %d]", input->dims->data[0], input->dims->data[1]);
    ESP_LOGI(TAG, "   Output: [%d, %d]", output->dims->data[0], output->dims->data[1]);
    ESP_LOGI(TAG, "   Arena used: %d / %d bytes", 
             interpreter->arena_used_bytes(), kTensorArenaSize);
    
    initialized = true;
    ESP_LOGI(TAG, "🎉 ML inference ready with ESP-NN acceleration!");
    
    return true;
}

float ml_inference_predict(const float features[25]) {
    if (!initialized) {
        ESP_LOGW(TAG, "ML inference not initialized!");
        return 0.0f;
    }
    
    // Start timing
    int64_t start_time = esp_timer_get_time();
    
    // Copy features to input tensor
    for (int i = 0; i < 25; i++) {
        input->data.f[i] = features[i];
    }
    
    // Run inference (ESP-NN accelerates this automatically!)
    TfLiteStatus invoke_status = interpreter->Invoke();
    if (invoke_status != kTfLiteOk) {
        ESP_LOGE(TAG, "Invoke() failed!");
        return 0.0f;
    }
    
    // Get output (probability of near-miss)
    float prob_near_miss = output->data.f[1];
    
    // Calculate inference time
    int64_t end_time = esp_timer_get_time();
    last_inference_time_ms = (end_time - start_time) / 1000;
    
    return prob_near_miss;
}

bool ml_inference_is_ready(void) {
    return initialized;
}

uint32_t ml_inference_get_latency_ms(void) {
    return last_inference_time_ms;
}
```

### Step 4: Integrate into Main Application

**File**: `main/main.c`

```c
#include "ml_inference.h"

// Scaler parameters (from Python training)
// Extract these from scaler.pkl after training
static const float scaler_mean[25] = {
    // ToF means (16 values) - example values
    450.0, 523.0, 612.0, 580.0, 490.0, 510.0, 520.0, 530.0,
    540.0, 550.0, 560.0, 570.0, 580.0, 590.0, 600.0, 610.0,
    // IMU means (9 values)
    0.0, 0.0, 0.0,      // roll, pitch, yaw
    0.0, 0.0, 9.81,     // accel_x, accel_y, accel_z
    0.0, 0.0, 0.0       // gyro_x, gyro_y, gyro_z
};

static const float scaler_std[25] = {
    // ToF stds (16 values) - example values
    200.0, 200.0, 200.0, 200.0, 200.0, 200.0, 200.0, 200.0,
    200.0, 200.0, 200.0, 200.0, 200.0, 200.0, 200.0, 200.0,
    // IMU stds (9 values)
    10.0, 10.0, 180.0,  // roll, pitch, yaw
    2.0, 2.0, 2.0,      // accel_x, accel_y, accel_z
    50.0, 50.0, 50.0    // gyro_x, gyro_y, gyro_z
};

void normalize_features(const tof_data_t *tof, const imu_data_t *imu, 
                       float features[25]) {
    int idx = 0;
    
    // ToF features (16)
    for (int i = 0; i < 16; i++) {
        features[idx] = (tof->distances[i] - scaler_mean[idx]) / scaler_std[idx];
        idx++;
    }
    
    // IMU features (9)
    features[idx] = (imu->roll - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->pitch - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->yaw - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->accel_x - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->accel_y - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->accel_z - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->gyro_x - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->gyro_y - scaler_mean[idx]) / scaler_std[idx]; idx++;
    features[idx] = (imu->gyro_z - scaler_mean[idx]) / scaler_std[idx]; idx++;
}

void app_main(void) {
    // ... existing initialization ...
    
    // Initialize ML inference with ESP-NN
    if (ml_inference_init()) {
        ESP_LOGI(TAG, "✅ ML inference enabled with ESP-NN acceleration");
    } else {
        ESP_LOGW(TAG, "⚠️  ML inference disabled (continuing without ML)");
    }
    
    // Main loop
    while (1) {
        // Read sensors
        bool tof_ok = sensor_manager_read_tof(&tof_data);
        bool imu_ok = sensor_manager_read_imu(&imu_data);
        
        // Run ML inference if ready
        if (ml_inference_is_ready() && tof_ok && imu_ok) {
            // Prepare features
            float features[25];
            normalize_features(&tof_data, &imu_data, features);
            
            // Run inference (ESP-NN accelerated!)
            float near_miss_prob = ml_inference_predict(features);
            
            // Detection threshold
            const float THRESHOLD = 0.70;  // 70% confidence
            
            if (near_miss_prob > THRESHOLD) {
                ESP_LOGW(TAG, "⚠️  NEAR-MISS DETECTED BY ML!");
                ESP_LOGW(TAG, "   Confidence: %.1f%%", near_miss_prob * 100);
                ESP_LOGW(TAG, "   Latency: %lu ms (ESP-NN accelerated)", 
                         ml_inference_get_latency_ms());
                
                // Set auto flag
                log_entry.flag_auto = 1;
                log_entry.confidence = near_miss_prob;
                
                // Visual/audio feedback
                led_set_color(LED_COLOR_ORANGE);
                buzzer_beep(3);
            }
        }
        
        // ... rest of loop ...
        vTaskDelay(pdMS_TO_TICKS(5));  // 200Hz loop
    }
}
```

## Troubleshooting

### Issue: "esp-tflite-micro not found"

**Solution:**
```bash
# Update component registry
idf.py reconfigure

# Or manually add to main/idf_component.yml
dependencies:
  espressif/esp-tflite-micro: "^1.3.1"
```

### Issue: "Inference is slow (>50ms)"

**Possible causes:**
1. ESP-NN not enabled
2. Tensor arena too small
3. Model too large

**Solutions:**
```bash
# 1. Verify ESP-NN is enabled
idf.py menuconfig
# → Component config → ESP-NN → [*] Enable

# 2. Increase tensor arena
constexpr int kTensorArenaSize = 20 * 1024;  // Try 20KB

# 3. Use quantized model (smaller, faster)
python tools/convert_to_tflite.py --quantize
```

### Issue: "Model won't load"

**Solution:**
```bash
# Regenerate model with correct TensorFlow version
pip install "tensorflow>=2.15,<3.0"
python tools/quick_start_ml.py
```
