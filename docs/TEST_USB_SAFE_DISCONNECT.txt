USB SAFE DISCONNECT - TEST GUIDE
=================================

BUILD AND FLASH:
----------------
idf.py build flash monitor


TEST 1: SAFE DISCONNECT (No Warning Expected)
----------------------------------------------
1. Press MODE button → Navigate to "USB Transfer" (Mode 7)
2. Press ACTION button → Activates USB mode
3. OLED shows: "Connect LEFT port to computer"
4. Connect USB cable to LEFT port (USB-OTG)
5. PC should recognize drive and show files
6. On PC: Safely eject the drive
   - Windows: Right-click → "Eject"
   - macOS: Drag to Trash or click Eject
   - Linux: Right-click → "Safely Remove"
7. Wait 2 seconds
8. Disconnect USB cable from LEFT port
9. Press ACTION button on device
10. EXPECTED: No warning screen
11. EXPECTED: OLED shows "Deactivating..." then "Logging resumed [OK]"
12. EXPECTED: Serial console shows "✓ USB host not connected - safe to deactivate"

RESULT: PASS / FAIL
Notes: _______________________________________________


TEST 2: UNSAFE DISCONNECT (Warning Expected)
---------------------------------------------
1. Press MODE button → Navigate to "USB Transfer" (Mode 7)
2. Press ACTION button → Activates USB mode
3. Connect USB cable to LEFT port (USB-OTG)
4. PC should recognize drive
5. WITHOUT ejecting on PC, press ACTION button
6. EXPECTED: Warning screen appears for 3 seconds:
   "!!! WARNING !!!"
   "USB still connected!"
   "Disconnect first"
7. EXPECTED: Then shows "Deactivating... (USB connected)"
8. EXPECTED: Serial console shows:
   "⚠️  USB host still connected!"
   "⚠️  Please disconnect USB cable from LEFT port first"
   "⚠️  Continuing anyway - data may be corrupted if transfer in progress"
9. EXPECTED: Mode deactivates after delay
10. EXPECTED: OLED shows "Logging resumed [OK]"

RESULT: PASS / FAIL
Notes: _______________________________________________


TEST 3: BUTTON RESPONSIVENESS
------------------------------
1. Activate USB Transfer mode (ACTION button)
2. Press ACTION button again (should deactivate)
3. Press ACTION button again (should activate)
4. Press ACTION button again (should deactivate)
5. EXPECTED: Each press is detected
6. EXPECTED: Mode toggles correctly
7. EXPECTED: No stuck states
8. EXPECTED: Serial console logs each button press

RESULT: PASS / FAIL

TEST 4: FILE TRANSFER DURING DISCONNECT (Risky!)
-------------------------------------------------
WARNING: This test may corrupt files - use test files only!

1. Activate USB Transfer mode
2. Connect USB cable to PC
3. Start copying a LARGE file (100+ MB) TO the device
4. While transfer in progress, press ACTION button
5. EXPECTED: Warning appears
6. EXPECTED: File transfer may fail
7. Check if file is corrupted (0 KB or won't open)

RESULT: PASS / FAIL
Notes: _______________________________________________


SERIAL CONSOLE MONITORING:
--------------------------
Watch for these messages:

SAFE DISCONNECT:
I (xxxxx) USB_MSC_SD: ✓ USB host not connected - safe to deactivate

UNSAFE DISCONNECT:
W (xxxxx) USB_MSC_SD: ⚠️  USB host still connected!
W (xxxxx) USB_MSC_SD: ⚠️  Please disconnect USB cable from LEFT port first


TROUBLESHOOTING:
----------------
Q: Warning appears even after ejecting?
A: Wait a few more seconds, PC might still be finalizing

Q: Button doesn't respond?
A: Check serial console for button press logs
A: Make sure you're in USB Transfer mode (Mode 7)

Q: Mode doesn't deactivate?
A: Check serial console for error messages
A: Try disconnecting USB cable first

Q: Files corrupted after test?
A: Expected if disconnected during active transfer
A: Re-copy files from backup
