╔═══════════════════════════════════════════════════════════════╗
║                GPS MODULE REWIRING INSTRUCTIONS               ║
╚═══════════════════════════════════════════════════════════════╝

PROBLEM:
  GPIO 43/44 are UART0 (console) pins - cannot be used for GPS
  That's why we saw "ToF: 20 19 21" instead of GPS data

SOLUTION:
  Use GPIO 38 and 47 instead

═══════════════════════════════════════════════════════════════

STEP 1: DISCONNECT OLD WIRING

  GPS Module          ESP32-S3
  ----------          --------
  TX        -X-X-X->  GPIO 43  (REMOVE THIS WIRE)
  RX        <-X-X-X-  GPIO 44  (REMOVE THIS WIRE)

═══════════════════════════════════════════════════════════════

STEP 2: CONNECT NEW WIRING

  GPS Module          ESP32-S3
  ----------          --------
  TX        ───────>  GPIO 47  ✅ (NEW CONNECTION)
  RX        <───────  GPIO 38  ✅ (NEW CONNECTION)
  VCC       ───────>  5V       (KEEP AS IS)
  GND       ───────>  GND      (KEEP AS IS)

═══════════════════════════════════════════════════════════════

IMPORTANT NOTES:

  ✅ Crossover is CORRECT:
     - GPS TX → ESP32 RX (GPIO 47)
     - GPS RX ← ESP32 TX (GPIO 38)

  ✅ Power connections stay the same:
     - GPS VCC → ESP32 5V
     - GPS GND → ESP32 GND

  ✅ Code is already updated - just rewire and flash!

═══════════════════════════════════════════════════════════════

STEP 3: BUILD AND FLASH

  1. Build: idf.py build
  2. Flash: idf.py flash monitor

═══════════════════════════════════════════════════════════════

STEP 4: VERIFY GPS IS WORKING

  Look for in console:
  
  ✅ I (XXX) MAIN: Wiring: TX=GPIO38, RX=GPIO47
  ✅ I (XXX) GPS: ✓ GPS initialized successfully
  ✅ I (5000) GPS: 📡 GPS UART active: XX bytes received
  ✅ Hex dump shows: 24 47 50 47 47 41 ($GPGGA...)
  
  NOT:
  ❌ 54 6f 46 3a 20 20 (ToF:   ) - This is console output!

═══════════════════════════════════════════════════════════════

QUICK REFERENCE:

  OLD (WRONG):  GPIO 43/44 (UART0 console pins)
  NEW (CORRECT): GPIO 38/47 (Free GPIO pins)
