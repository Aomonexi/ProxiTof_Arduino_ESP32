SUMMARY
-------

✅ SAFE TO EXIT:
   - Status: WAITING
   - No PC connected
   - Press ACTION anytime

⚠️ EJECT FIRST:
   - Status: READY
   - PC actively accessing SD
   - Must eject on PC before ACTION

⚠️ PROBABLY SAFE:
   - Status: SUSPENDED
   - PC idle/sleep
   - Eject if possible, then ACTION

🔄 REAL-TIME UPDATES:
   - Status updates every 100ms
   - Changes visible within 1 second
   - Always shows current state

📊 LIVE FEEDBACK:
   - Know exactly when safe to exit
   - See PC connection status
   - Clear guidance on OLED
