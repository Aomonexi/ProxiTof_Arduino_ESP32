# Processed Training Data

**Purpose**: Intermediate files generated during ML training

---

## Files Generated Here

### During Training

1. **`X_train.npy`** - Training features (normalized)
2. **`X_test.npy`** - Test features (normalized)
3. **`y_train.npy`** - Training labels
4. **`y_test.npy`** - Test labels
5. **`scaler.pkl`** - Feature normalization parameters

### After Training

6. **`training_metrics.txt`** - Model performance metrics
7. **`confusion_matrix.png`** - Classification results visualization

---

## What These Files Do

**Feature Files** (`X_*.npy`):
- Contain 25 normalized features per sample
- 16 ToF distances + 9 IMU values
- Split 80% training, 20% testing

**Label Files** (`y_*.npy`):
- Binary labels: 1 = near-miss, 0 = safe
- Extracted from `flag_manual` column

**Scaler** (`scaler.pkl`):
- Mean and standard deviation for each feature
- Used to normalize features before inference
- Critical for model accuracy

---

## Do Not Edit

These files are automatically generated by `quick_start_ml.py`.

If you need to retrain:
1. Delete all files in this folder
2. Run `python tools/quick_start_ml.py` again
